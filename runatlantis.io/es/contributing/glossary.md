# Glosario

La comunidad de Atlantis usa muchas palabras y frases para trabajar de manera más eficiente.
Encontrarás las más comunes y su significado en esta página.

## Evento de Pull / Merge Request

Los diferentes VCS tienen distintos nombres para fusionar cambios. Atlantis usa el
nombre Pull Request como abstracción. El proveedor de VCS implementa esta
abstracción y reenvía la llamada a la función respectiva.

## VCS

VCS significa Version Control System.

Atlantis solo soporta git como Version Control System. Sin embargo, hay
soporte para múltiples proveedores de VCS. Actualmente, soporta los siguientes
proveedores:

- [Azure DevOps](https://azure.microsoft.com/en-us/products/devops)
- [BitBucket](https://bitbucket.org/)
- [GitHub](https://github.com/)
- [GitLab](https://gitlab.com/)
- [Gitea](https://gitea.com/)

El término VCS se usa tanto para git como para los diferentes proveedores de VCS.
